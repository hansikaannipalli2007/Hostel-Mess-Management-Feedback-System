# Hostel Mess Management & Feedback System

A Java Swing-based desktop application developed to manage daily hostel mess menus and collect student feedback for individual meals.

## Motivation

This project was developed based on a real situation observed in the hostel mess, where students were asked to provide feedback about the meals. Since feedback was collected manually, there was a need for a more organized and convenient way to record, manage, and review student responses.

The system was developed to make the feedback process easier for students and more structured for mess management, while maintaining meal-wise feedback records.

## Features

* Student details registration
* Daily menu verification and display
* Feedback for Breakfast, Lunch, Snacks, and Dinner
* Rating from 1–5 with comments
* Duplicate feedback prevention using Roll Number + Meal + Date
* Management login
* Add and update daily menus
* View feedback records
* Filter feedback meal-wise
* CSV-based data storage

## Project Structure

The project is organized into separate classes for students, meals, feedback, menu management, data handling, and GUI screens.

## How to Run

1. Clone or download the repository.
2. Open the project in a Java-supported IDE.
3. Compile all `.java` files.
4. Run `Main.java`.

The required CSV files are created automatically when the application starts.

## Project Purpose

The system provides a simple digital solution for managing hostel mess menus and collecting structured student feedback for different meals. It helps students provide feedback conveniently and allows management to maintain and review meal-wise feedback records.
